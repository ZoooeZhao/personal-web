## Replacing An Image

Upload `image-02.png`, `image-03.png`, or `image-04.png` as separate, already-cropped replacements for the infographic panels. Local replacements will not be cropped a second time. The three original-source panels are cropped from the existing horizontal infographic automatically.

For any other slot, upload `image-NN.png` (or WebP, JPG, JPEG, SVG, GIF), using the new two-digit number shown on the page. One file per number. The next Vite build matches local files automatically. For slots that used to be a GIF, a static PNG/WebP replacement is supported.
